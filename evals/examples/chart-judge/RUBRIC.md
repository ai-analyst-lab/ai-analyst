# Chart-takeaway judge rubric

Rubric version: working-1

Score each rule as `pass`, `fail`, or `unknown`. Return `unknown` when the chart does not contain
enough evidence to make the judgment. The chart passes overall only when every rule passes.

## Rules

Add the first narrow rule before running the judge. Every rule needs:

- a short name;
- the behavior it evaluates;
- a concrete pass anchor;
- a concrete fail anchor; and
- an unknown condition.

Revise one rule at a time when a disagreement reveals a specific gap.
