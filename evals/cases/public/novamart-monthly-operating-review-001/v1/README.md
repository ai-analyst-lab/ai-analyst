# NovaMart monthly operating review

## Your task

Prepare the monthly operating review defined in `case.yaml`. Save all six required files in the draft directory created by the evaluation start command.

The case evaluates the finished analytical output. It does not require one specific internal agent path. Use the existing AI Analyst system, Snowflake connection, skills, validation, and trace capabilities as appropriate.

## Required files

- `result.json`
- `monthly-results.csv`
- `brief.md`
- `chart.png`
- `chart-data.csv`
- `calculation.sql`

The answer key and graders are intentionally absent during the first run. After the output is locked, the course evaluation repository can grade it and write a student-safe report into the run directory.
